A responsive sidebar component for documentation navigation with collapsible sections, active state tracking, and mobile support.

## Usage

```tsx
import { Button } from "@/components/ui/button"

// Sidebar structure
<nav className="sidebar">
  <div className="sidebar-header">
    <h2>Documentation</h2>
  </div>
  <div className="sidebar-content">
    <ul className="sidebar-nav">
      <li><a href="/getting-started">Getting Started</a></li>
      <li><a href="/installation">Installation</a></li>
      <li><a href="/configuration">Configuration</a></li>
    </ul>
  </div>
</nav>
```

## Features

- **Collapsible Sections**: Group related navigation items with expandable headers
- **Active State Tracking**: Automatically highlights the current page
- **Mobile Responsive**: Slides in/out on mobile devices
- **Keyboard Accessible**: Full keyboard navigation support
- **Customizable**: Flexible styling with CSS variables

## Collapsible Sections

Create nested navigation with collapsible groups:

```tsx
<div className="sidebar-section">
  <button className="sidebar-section-header">
    <span>Components</span>
    <ChevronDown className="h-4 w-4" />
  </button>
  <ul className="sidebar-section-items">
    <li><a href="/components/button">Button</a></li>
    <li><a href="/components/card">Card</a></li>
    <li><a href="/components/table">Table</a></li>
  </ul>
</div>
```

## Responsive Behavior

The sidebar automatically adapts to different screen sizes:

- **Desktop** (&gt;1024px): Fixed sidebar visible at all times
- **Tablet** (768-1024px): Collapsible sidebar with toggle button
- **Mobile** (&lt;768px): Full-screen overlay with slide animation

## Best Practices

1. **Organization**: Group related items logically
2. **Depth**: Avoid nesting more than 2-3 levels deep
3. **Labels**: Use clear, concise navigation labels
4. **Active States**: Clearly indicate the current page
5. **Mobile UX**: Ensure touch-friendly tap targets
