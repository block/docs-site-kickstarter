```css
body {
  font-synthesis-weight: none;
  text-rendering: optimizeLegibility;
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
}
```

## Best Practices

1. **Heading Hierarchy**: Always follow proper heading order (h1 → h2 → h3)
2. **Line Length**: Keep content width around 65-75 characters for readability
3. **Font Weights**: Use the designated weights for each heading level
4. **Spacing**: Maintain consistent spacing between text elements
5. **Contrast**: Ensure text meets WCAG AA contrast requirements
