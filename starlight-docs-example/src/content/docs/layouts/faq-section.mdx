The FAQ Section component creates interactive frequently asked questions sections with accordion functionality.

## Usage

```astro
---
import FAQSection from "@/components/block/FAQSection.astro"

const faqs = [
  {
    question: "What is Block?",
    answer: "Block is an open-source design system and documentation template built with Astro.",
  },
  {
    question: "Is it free to use?",
    answer: "Yes, Block is completely free and open-source under the MIT license.",
  },
];
---

<FAQSection
  title="Frequently Asked Questions"
  description="Find answers to common questions."
  faqs={faqs}
/>
```

<Accordion label="What is Block?">
  <AccordionContent>

## Variants

### Default

Uses the standard accordion styling with card-based design:

```astro
<FAQSection faqs={faqs} variant="default" />
```

### Bordered

Clean design with borders but no background fill:

```astro
<FAQSection faqs={faqs} variant="bordered" />
```

### Minimal

Ultra-clean design with just bottom borders:

```astro
<FAQSection faqs={faqs} variant="minimal" />
```

## Props

| Prop        | Type                                        | Default     | Description                    |
|-------------|---------------------------------------------|-------------|--------------------------------|
| title       | `string`                                    | -           | Section heading                |
| description | `string`                                    | -           | Section description            |
| faqs        | `{ question: string, answer: string }[]`    | `[]`        | Array of FAQ items             |
| variant     | `'default' \| 'bordered' \| 'minimal'`      | `'default'` | Visual style variant           |

## Comparison with Accordion

| Feature | Accordion | FAQ Section |
|---------|-----------|-------------|
| **Purpose** | Individual collapsible items | Complete FAQ page section |
| **Usage** | Single accordion per component | Multiple FAQs in one component |
| **Header** | Just the accordion label | Includes title, tagline, description |
| **Content** | Flexible content via AccordionContent | Text-based FAQ answers |
| **Layout** | Individual item control | Managed group layout |

Choose **Accordion** for individual control over collapsible items, and **FAQ Section** for a complete FAQ implementation.
